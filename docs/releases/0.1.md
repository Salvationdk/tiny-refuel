# Tiny Refuel 0.1

[![Add to HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=Salvationdk&repository=tiny-refuel&category=integration)

Første udgave med benzin, diesel og opladning samlet i én HACS-integration. Kort, visuel editor, scraper, selskabslogoer og bilkatalog følger med.

- Bilvalg og visning efter drivmiddel.
- Ladeoversigt med lokale priser, generelle takster og datastatus.
- Nærmeste steder med afstand i luftlinje og navigation via Waze eller Google Maps.
- Én fælles knap til at hente nye data.

[Se billeder fra installationen og installationsvejledning](https://github.com/Salvationdk/tiny-refuel#eksempler-fra-v01).

Efter HACS-download: genstart Home Assistant, tilføj Tiny Refuel under Enheder og tjenester, og genindlæs browseren.

Teknisk integrationsversion: 0.1.0. Integrationstests er gennemført mod Home Assistant 2025.11.2. Test mod 2026.10 mangler endnu; skærmbillederne viser resultatet fra brugerens installation.
