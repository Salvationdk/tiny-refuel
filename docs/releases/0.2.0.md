# Tiny Refuel 0.2.0

## Forbedringer

- Bevarer det stående kortlayout og viser brændstofudbydere og elstationer i fem kolonner, når skærmen er bred og liggende.
- Beholder benzin-, diesel- og elpriser, adresser, afstande, kundefordele, navigation, filtre og muligheden for at vise flere elstationer.
- Viser status pr. brændstofkilde med seneste kontrol, antal stationer/priser, manglende koordinater og kildefejl.
- Viser tilsvarende status for ladekilder og tydelig markering af gemte brændstofpriser, når en hentning fejler.
- Viser hvor mange stationadresser der stadig mangler koordinater; geokodning fortsætter gradvist ved senere hentninger.
- Opdaterer dokumentation og regressionstests for de nye statusfelter og responsive lister.

## Opgradering

Efter installation gennem HACS genstartes Home Assistant, hvorefter browseren genindlæses. Første datastatus udfyldes ved næste hentning. Eksisterende lagrede priser, adresser og historik bevares.

Skærmbillederne i README er fortsat fra v0.1 og bør udskiftes efter afprøvning af denne version.
