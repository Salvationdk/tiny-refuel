# Tiny Refuel 0.1.1

Retter tomme Go’on- og Shell-rækker, når en position er valgt, men stationernes koordinater endnu mangler.

- Tilgængelige priser og adresser vises med besked om manglende koordinater. Den viste station er ikke nødvendigvis den nærmeste.
- Ved delvis koordinatdækning angives, at afstanden kun sammenlignes mellem stationer med kendte koordinater.
- De højst 30 nye adresseopslag pr. hentning fordeles på skift mellem selskaberne. Cachede og gentagne adresser sorteres fra først.
- Koordinatcache og prisdata bevares. Browserressourcens versionsnummer opdateres til 0.1.1.

Efter opdatering: genstart Home Assistant og genindlæs browseren med Ctrl+F5. Start en hentning for at fortsætte koordinatopslagene. Fuld koordinatdækning kræver fortsat flere hentninger; adresser uden søgeresultat kan stadig mangle koordinater.
