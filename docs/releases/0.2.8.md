## Tiny Refuel 0.2.8 – Home Assistant Marketplace

### Kompatibilitet
- Home Assistant 2026.11.0 er tilføjet til Python- og frontendtestmatrixen. 2025.11.2 og 2026.10.0 bevares.
- Visuelle tests af kort og editor er opdateret til Home Assistant 2026.11 med matchende frontend og intents.
- Native Marketplace-manifestvalidering gennem Home Assistant 2026.11's egen kode tester både nyinstallation og versionopdatering i et isoleret miljø. Det erstatter ikke en komplet live Marketplace-downloadtest.
- Integrationen er kategoriseret som energipriser og elbilopladning.

### Installation og dokumentation
- Direkte Marketplace-link og instruktioner til Home Assistant 2026.11+.
- HACS-vejledning til ældre understøttede installationer er bevaret.
- Ingen ændringer af eksisterende dashboardopsætninger eller lagrede data.

### Udgivelse
v0.2.8 oprettes med et nyt tag, og kun efter beståede kontroller. Tidligere offentliggjorte v0.2.7 må ikke ændres.
