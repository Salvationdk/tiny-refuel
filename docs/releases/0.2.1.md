# Tiny Refuel 0.2.1

## Rettelser

- Strammer filtreringen af kundeanmeldelser og kommentarer på udbydernes sider.
- Ignorerer også kundeudtalelser uden tydelig HTML-mærkning.
- Genhenter ældre fordelsdata, så tekster fra den tidligere filtrering ikke fortsætter i kortet.

## Opgradering

Efter installation gennem HACS genstartes Home Assistant, og browseren genindlæses. Fordelsoplysninger hentes igen med den opdaterede filtrering.
