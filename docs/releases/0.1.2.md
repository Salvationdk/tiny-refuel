# Tiny Refuel 0.1.2

Tesla-ladesteder viser nu to separate priser: **Tesla/medlemmer** og **Andre biler uden medlemskab**. Begge priser vises i kortet og i listen over ladesteder.

- Lokale priser, maksimal effekt og antal ladepunkter hentes fra Teslas offentlige stationssider.
- Adgang for andre bilmærker angives pr. station.
- Tidsafhængige priser vises med prisinterval og oplyste tidsvilkår.
- Manglende priser forbliver ukendte. Ved hentefejl markeres eventuelle gemte priser med oprindelig hentetid.
- Minutegebyrer, roamingpriser og andre valutaer bruges ikke som almindelig kWh-pris.
- Begge pristyper på samme sted tæller som ét ladested med lokal pris.

Priserne er øjebliksbilleder. Medlemsabonnement og ekstra gebyrer er ikke medregnet. Tesla kan fortsat afvise hentninger med HTTP 403; denne udgave omgår ikke adgangsbegrænsninger.

Efter opdatering: genstart Home Assistant, genindlæs browseren med Ctrl+F5, og tryk **Scrape alle data**.
