# Tiny Refuel 0.2.9 – F24/Q8 og ladepriser (Issue #23)

## Rettelser

- **F24/Q8:** Den fælles JSON-kilde er flyttet fra de ophørte `www.f24.dk`/`www.q8.dk`-adresser (HTTP 404) til `beta.q8.dk/Station/GetStationPrices`. Den blev verificeret med HTTP 200 og 243 stationer i et realtidscheck fra GitHub Actions den 9. november 2026.
- **Q8-ladepriser:** 150 kW- og 22 kW-takster bliver nu udlæst fra Q8 Erhvervs faktiske HTML-tabel. De to kolonner kontrolleres separat. Priserne hentes ved hver indsamling og er **ikke hardcodede**.
- **Fejlsikring:** En 22 kW-pris kan ikke forveksles med prisen på en 150 kW-lynladning. Manglende/ugyldige takster rapporteres som kildefejl i stedet for at blive gættet. Cachede kildepriser bevares ved forbigående fejl efter eksisterende logik.
- **Regressionstests:** Ny testfil dækker den fælles F24/Q8-kilde, begge brændstofmærker, fjernede HTTP 404-endpoints, midlertidige fejl og ladepristabeller.

## Installation

Installer opdateringen gennem Home Assistant Marketplace (2026.11+) eller HACS (ældre understøttede versioner). Genstart Home Assistant efter opdateringen.

## Understøttelse

Home Assistant 2025.11.2, 2026.10.0 og 2026.11.0 indgår fortsat i kompatibilitetstests. Den særskilte lokale `/config/scripts/fuelprices_self.py` og dens `command_line`-sensor er **ikke en del af Tiny Refuel** og ændres ikke af denne release.
