# Tiny Refuel 0.1.3

Flere offentlige ladetakster vises nu sammen med ladenetværkenes stationer:

- Circle K: daglig offentlig listepris for lynladning med kildens dato.
- E.ON Drive: offentlig dansk startpris for AC og DC.
- IONITY: danske kWh-minimumspriser for Power, Motion, Go og direkte betaling, med abonnementsgebyrer vist i etiketterne.
- IONITYs forbehold om, at den konkrete stationspris kan være højere, vises ved taksterne.
- Generelle takster er fortsat markeret særskilt og tæller ikke som en bekræftet lokal stationspris.

Clever viser dynamiske priser, som afhænger af ladepunkt og tidspunkt. Integrationens offentlige lokationsfeed indeholder ikke disse priser, så Clever-prisen henviser fortsat til Clevers app eller ladekort.

Efter opdatering: genstart Home Assistant, genindlæs browseren med Ctrl+F5, og tryk **Scrape alle data**.
